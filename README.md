# Associação Beneficente Anjos do Lar

Projeto acadêmico desenvolvido com JavaScript, Vite Plus e Express.

## Tecnologias utilizadas

- JavaScript
- Vite Plus
- Node.js
- Express
- Dotenv

## Como instalar

Abra o terminal na pasta do projeto e execute:

```bash
npm install
```

## Como executar

É necessário abrir dois terminais no VS Code.

**Terminal 1 — Iniciar a API:**

```bash
npm run api
```

**Terminal 2 — Iniciar a aplicação:**

```bash
npm run dev
```

Abra no navegador o endereço apresentado pelo Vite, normalmente:

http://localhost:5173

## Testar a API

Acesse:

http://localhost:3000/api/health

A API deverá retornar o status de funcionamento do sistema como `ok`.

## Objetivo do projeto

Desenvolver um sistema para auxiliar a Associação Beneficente Anjos do Lar na gestão de voluntários, doações e estoque solidário.
